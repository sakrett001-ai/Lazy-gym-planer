# Lazy Gym Planner — планировщик тренировок

Подбирает тренировку или недельную программу под мышцы, оборудование, цель и формат; показывает технику анимированной фигурой; ведёт журнал весов и подсказывает, когда прибавлять.

## Как пользоваться

- **На телефоне**: откройте https://sakrett001-ai.github.io/Lazy-gym-planer/ (английская версия — https://sakrett001-ai.github.io/Lazy-gym-planer/en/ ), в меню браузера — «Добавить на главный экран». Работает без интернета.
- **Офлайн-файл**: `dist/lazy-gym-planner-offline-ru.html` / `-en.html` — один файл, открывается в любом браузере.

## Разработка

```
node build.js        # собрать dist/
npm run check        # регрессионные тесты, аудит движений, сборка и синтаксис RU/EN
npm run audit        # проверить движения без сборки и браузера
npm run serve        # собрать и открыть на http://localhost:8080
npm run deploy       # собрать и опубликовать на GitHub Pages (ветка gh-pages)
npm run i18n         # проверить, какие русские строки ещё не переведены (i18n/missing.en.json)
```

## Языки

Исходники на русском. Английская версия получается при сборке: `i18n/translate.js` находит все строки с кириллицей в JS, HTML и CSS и подставляет перевод из словаря `i18n/en.json` (ключ — русская строка целиком; для шаблонов `${…}` — каждый кусок текста отдельно). Добавили упражнение или текст — запустите `npm run i18n`, допишите новые ключи из `i18n/missing.en.json` в `i18n/en.json`, пересоберите. Непереведённое остаётся по-русски, сборка об этом предупреждает. Правила и глоссарий — `i18n/GLOSSARY.md`.

Публикация идёт через ветку `gh-pages` (Settings → Pages → Deploy from a branch → gh-pages / root) — GitHub Actions не нужны.

Единственная зависимость — парсер `acorn` для перевода (`npm install`). Исходники в `src/`:

## Проверка движений

`npm run audit` проверяет 101 положение каждого упражнения, обе стороны тела и каждый объявленный ракурс 3D-моделей. Контролирует конечность координат, непрерывность, длину костей, хват за гриф/гантели, неподвижные опоры, поддержку головы скамьёй, прямые руки в тягах и направление локтей в жимах. В тяге гантелей с опорой грудью проверяет фактическую геометрию подушки: расположение перед грудью, контакт поверхности, длину покрытия, направление и наклон. Для мышечного пилота проверяет конечность поверхностей, сохранность позы, диапазон кривых и отсутствие скачков на развороте. Неизвестный ракурс также даёт ошибку. Ошибки дают код выхода 1.

```sh
node tools/biomechanics-audit.js --json          # машиночитаемый отчёт
node tools/biomechanics-audit.js --only spatial # только пространственные модели
node tools/biomechanics-audit.js --samples 201  # более плотная проверка
python3 tools/joints-audit.py                   # совместимый запуск проверки боковых схем
python3 tools/rig3d-elbows.py                   # координаты обоих локтей в пяти фазах
```

Скрипты запускаются из любой рабочей папки, не требуют Playwright или `dist/`. `npm test` содержит также отрицательные проверки: искусственный отрыв кисти между ключевыми кадрами, скольжение стопы, неверная длина кости, голова за краем скамьи и локоть за плоскостью плеча должны обнаруживаться. Проверки опоры грудью воспроизводят прежнюю скамью на спине, зазор до груди, краткий отрыв корпуса, неверный угол, отсутствие подушки и скольжение стоп в боковой схеме.

`REVIEW` — отдельные сигналы для визуальной проверки. По знаку сгиба в боковой 2D-проекции нельзя доказать анатомическую ошибку: вращение плеча и движение вне плоскости рисунка могут изменить знак. Сейчас остаются сигналы по шести упражнениям: `invrow`, `tablerow`, `goodmorning`, `burpee`, `plankup`, `cableohext`. Их не скрываем и не выдаём за доказанно правильные движения. Аудит не оценивает индивидуальную подвижность, безопасность для конкретного человека, мышечную силу и все возможные столкновения тела с реквизитом.

Для нового пространственного упражнения добавьте правила хвата и опор в `CONTACT_RULES` в `tools/biomechanics-audit.js`. Не фиксируйте точки, которым разрешено двигаться: при подтягивании свободны ноги, в выпаде задняя пятка поворачивается вокруг опорного носка.

## Мышцы по фазам

В 4.1.6 подсветка доступна для жима штанги лёжа, тяги верхнего блока и приседа со штангой. В атласе и тренировке переключатель «Мышцы по фазам» включает зоны и легенду; настройка применяется также к карточкам и сохраняется локально. Цвет означает условную яркость учебного рисунка, не измеренную силу или ЭМГ. Для остальных упражнений сохраняется нейтральный силуэт.

Профили и анатомические поверхности — `src/js/09b-muscle-profiles.js`, отрисовка — `07-rigs-core.js`. У каждой мышцы есть роль и две кривые: `concentric`/`eccentric`, по три узла для `t=0, .5, 1`. Значения 0–1 управляют только яркостью. Крайние узлы двух кривых должны совпадать; пауза использует значение соответствующей точки. Новые кривые явно помечайте `illustrative` и отделяйте источники состава мышц от гипотез о распределении яркости.

Для жима доступен ракурс сверху под углом; для тяги и приседа — сзади. В режиме двух ракурсов обе фигуры показывают одинаковую фазу. [Реализованный пилот и план более реалистичного тела](docs/mannequin-roadmap.md).
