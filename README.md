# Подход — планировщик тренировок

Подбирает тренировку или недельную программу под мышцы, оборудование, цель и формат; показывает технику анимированной фигурой; ведёт журнал весов и подсказывает, когда прибавлять.

## Как пользоваться

- **На телефоне**: откройте https://sakrett001-ai.github.io/Lazy-gym-planer/ , в меню браузера — «Добавить на главный экран». Работает без интернета.
- **Офлайн-файл**: `dist/podhod-offline.html` — один файл, открывается в любом браузере.

## Разработка

```
node build.js        # собрать dist/
npm run serve        # собрать и открыть на http://localhost:8080
npm run deploy       # собрать и опубликовать на GitHub Pages (ветка gh-pages)
```

Публикация идёт через ветку `gh-pages` (Settings → Pages → Deploy from a branch → gh-pages / root) — GitHub Actions не нужны.

Зависимостей нет. Исходники в `src/`:

| Папка / файл | Что внутри |
|---|---|
| `src/js/00-engine.js` | движок фигуры: кинематика, реквизит, карта мышц |
| `src/js/01–04-exercises-*.js` | база упражнений (базовая, скамьи и кардио, с собственным весом) |
| `src/js/03-motion-demo.js`, `05-motion-cues.js`, `06-motion-sources.js` | атлас движений: фазы, подсказки, источники |
| `src/js/07–09-rigs-*.js` | пространственные скелеты с двумя ракурсами |
| `src/js/10-progressions.js` | лестницы сложности |
| `src/js/11-planner.js` | подбор, дозировка, программа на неделю, отрисовка |
| `src/js/12-motion-player.js` | проигрыватель движений в карточках и атласе |
| `src/js/13-log.js` | журнал: запись подходов, подсказки веса, история, экспорт |
| `src/js/14-workout-mode.js` | режим тренировки |
| `src/js/15-autoreg.js`, `16-ics.js`, `17-warmup.js` | авторегулировка, календарь, разминка и блины |
| `src/css/` | стили по слоям |
| `src/body.html` | разметка страницы |
| `src/sw.js`, `src/pwa.js`, `src/manifest.webmanifest` | PWA |

Файлы склеиваются в алфавитном порядке, поэтому префикс с номером задаёт порядок выполнения. Новое направление упражнений — отдельный файл `src/js/0N-exercises-<имя>.js` с `EX.push(...)`.

## Версия

Номер в `package.json`. При изменении номера сервис-воркер обновит кеш у всех, кто поставил приложение.
