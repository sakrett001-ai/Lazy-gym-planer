# Авторинг упражнений на манекене атласа

Документ для людей и агентов, которые переводят упражнения атласа на манекен.
Цель — сцена, которую тренер посмотрит и не найдёт ошибки: суставы в физиологических пределах,
тело не проходит сквозь снаряды, пол и само себя, тренажёры в реальных размерах и собраны,
опоры и хваты настоящие, техника соответствует подсказкам упражнения.

## Координаты

* Внутренние координаты авторинга: **сантиметры, Y вверх, пол Y = 0, правая тройка**.
* В нейтральной позе тело смотрит вдоль **+Z**, **левая сторона тела — +X**, правая — −X.
  Сторона `'L'` имеет знак `M.SIGN.L = +1`, `'R'` — `−1`.
* Ориентацию таза задаёт `C.root(q, p, up, fwd)`: `up` — направление вдоль позвоночника к голове,
  `fwd` — куда смотрит живот. Левую сторону система вычисляет сама (`x = up × fwd`).
  Примеры: стоя лицом к +Z — `up=[0,1,0], fwd=[0,0,1]`; лёжа на спине головой к +Z —
  `up=[0,0,1], fwd=[0,1,0]` (тогда левая рука окажется на −X); лёжа на животе головой к +Z —
  `up=[0,0,1], fwd=[0,-1,0]` (левая рука на +X).
* Чтобы не путаться в сторонах, берите латеральное направление из позы: `C.lat(q, s)` (по грудной
  клетке) или `C.latP(q, s)` (по тазу) — это вектор «наружу» для стороны `s`.
* В приложение поза уходит в координатах каталога (Y вниз, пол 186) — это делает рантайм, авторам не нужно.

## Тело и его степени свободы

`q = C.base()` — нейтральная стойка. Поля (градусы):

* `q.root.p` — середина между тазобедренными суставами; `q.root.q` — кватернион таза (через `C.root`).
* `q.lumbar`, `q.thoracic`, `q.neck` — `[сгибание вперёд +, наклон вправо +, поворот влево +]`.
  `C.trunk(q, flex, lat, rot)` делит сгибание между поясницей и грудным отделом.
* Для каждой стороны `q.L` / `q.R`:
  `girdle [поднимание +, протракция +]` — плечевой пояс (шраги, сведение/разведение лопаток);
  `shoulder [сгибание, отведение, наружная ротация]`; `elbow`; `pron` (0 — большой палец «вперёд»,
  −90 — ладонь вперёд/супинация); `wrist [к ладони +, лучевое +]`;
  `hip [сгибание, отведение, наружная ротация]`; `knee`; `ankle [тыльное +, супинация +]`;
  `mtp` (разгибание пальцев, при подъёме пятки).
* Обычно руки и ноги ставятся обратной кинематикой, а углы получаются сами.

Высоты в нейтральной стойке (в кроссовках, подошва 2 см): тазобедренные 94,5; плечевые ≈140;
локти ≈112; запястья ≈85; колени ≈52; голеностопы 8,5; макушка ≈177. Плечо 28,3 см, предплечье 27,
бедро 42,4, голень 43,6. Центр хвата — 8 см от запястья и 2,6 см в сторону ладони.
Сидя на плоском сиденье тазобедренные суставы на ≈9–10 см выше сиденья.

## Помощники (`C` в `pose(t, C)`)

| Помощник | Что делает |
|---|---|
| `C.root(q, p, up, fwd)` | таз в точку и ориентацию |
| `C.restOn(q, region, point, normal, gap)` | положить область тела на плоскость (сдвиг таза по нормали); `gap` −1…−1,5 — поджатие тканей и обивки |
| `C.restOn2(q, a, b, point, normal, gap)` | две области на одной плоскости (лопатки и ягодицы при прогибе): подбирает наклон таза |
| `C.neckTo(q, region, point, normal)` | подобрать сгибание шеи, чтобы затылок лёг на скамью |
| `C.rootAtHip(q, s, p)`, `C.rootAtShoulders(q, p)` | поставить таз так, чтобы тазобедренный сустав / середина плеч оказались в точке |
| `C.grip(q, s, point, thumb, pole, {wristExt})` | хват **жёсткой ручки** (гриф, турник, рукоять тренажёра): центр хвата в точку, `thumb` — куда смотрит большой палец вдоль ручки, `pole` — куда смотрит локоть |
| `C.hold(q, s, point, pole, {pron, flex, dev})` | **свободный снаряд** (гантель, гиря, канат): кисть продолжает предплечье с заданной пронацией, снаряд следует за кистью |
| `C.palm(q, s, point, fingers, up, pole)` | ладонь лежит на опоре (упор лёжа, на скамью) |
| `C.armTo(q, s, wrist, pole, {pron, mode})` | свободная рука (махи, прыжки) |
| `C.foot(q, s, support, yaw, pole, {forward, heel})` | стопа на опоре: `support` — точка под подушечкой стопы, `forward` — направление носка, `heel` — подъём пятки, град |
| `C.heel(q, s, support, yaw, pitch, pole)` | упор пяткой, носок поднят на `pitch` |
| `C.kneel(q, s, contact, shin, up, {toes})` | колено и голень на опоре; таз должен стоять так, чтобы бедро дотягивалось (`rootAtHip`) |
| `C.legTo(q, s, ankle, pole, {dorsi})` | свободная нога |
| `C.rhythm(q, s)` | лопаточно-плечевой ритм для поднятой руки |
| `C.com(q, loads)`, `C.balanceOver(q, target, {loads, resolve})` | центр масс и балансировка стоя: сдвиг таза, после каждого шага `resolve(q)` заново ставит стопы и кисти |
| `C.lat`, `C.latP`, `C.axes(q, seg)` | направления и рамки сегментов |
| `C.chestPoint(q, h)` | точка передней поверхности корпуса на высоте `h` (от тазобедренных суставов вдоль корпуса) |
| `C.solve1D(f, lo, hi)` | подбор одного параметра (например, наклона тела, чтобы грудь коснулась грифа) |
| `C.point(eqId, name)`, `C.frame(eqId, name)` | опорные точки и рамки инвентаря (`anchor`/`frameAnchor` в типе) |

Области тела для `restOn` и контактов: `back`, `upperBack`, `chest`, `belly`, `front`, `buttocks`,
`thighsBack`, `headBack`, `headAll`, `uaL/R`, `faL/R`, `thL/R`, `skL/R`, `kneeL/R`, `shinL/R`.
Для контактов дополнительно: `soleL/R` (подошва), `footL/R` (вся обувь), `palmL/R`, `gripL/R`.

**Порядок построения позы**: корпус и таз (углы, `root`) → опора (`restOn`) → стопы (`foot`/`kneel`) →
кисти (`grip`/`hold`/`palm`). Если опора — только пол, после постановки стоп и рук проверьте баланс
(`balanceOver`).

## Спецификация упражнения

```js
module.exports = {
  bbbench: {
    keys: [0, .25, .5, .75, 1],                 // моменты запекания; для сложных движений 7–9 ключей
    equipment: [{ type: 'flatBench', id: 'bench' }, { type: 'barbell', id: 'bar', plates: [20, 5] }],
    contacts: [{ body: 'back', prop: 'bench:pad' }, { body: 'soleL', prop: 'floor' }, { body: 'gripL', prop: 'bar' }],
    gripRadius: { L: 1.4, R: 1.4 },             // радиус ручки для пальцев (гриф 1,4; гантель 1,6)
    dynamic: false,                              // true — прыжки и махи: не проверять равновесие
    pose(t, C) { const q = C.base(); /* … */ return q; }
  }
};
```

* `t` — фаза от 0 до 1. Плеер идёт 0→1 (рабочая фаза или опускание, если у упражнения `eccFirst`),
  держит, возвращается 1→0. Для `eccFirst` (жимы, приседания): `t = 0` — верх, `t = 1` — низ.
  Для остальных: `t = 0` — исходное положение, `t = 1` — конечная точка рабочей фазы.
  Для удержаний (`hold`) показывается только `t = 0`. Смотрите `anim.eccFirst`, `anim.hold`, `anim.cues`
  в исходных описаниях (`src/js/01-…04b-exercises-*.js`).
* Ключи интерполируются монотонной кубической кривой по углам. Между ключами контакты могут
  «плыть» на миллиметры — поэтому для движений по дуге берите больше ключей.
* `pose` вызывается для каждого ключа независимо: не храните состояние между вызовами
  (кэшировать вычисленную раскладку можно, см. `once` в `pilot.js`).
* Односторонние упражнения работают той стороной, что задана в `CATALOG_LATERALITY`
  (`src/js/09d-catalog-muscles.js`): dbrow, concentration, kickback — левая рука; cablelat, archer —
  правая; bulgarian, stepup, lunge, revlunge, pistolbox, sllift, glutebridge1, glutekick, calf1 — левая
  нога; sidelunge — правая.
* Варианты снаряжения: элемент списка `equipment` с `optional: 'kb'` показывается, только если у
  пользователя есть гиря; `optionalNot: 'kb'` — только если её нет. Так одна поза обслуживает
  «гантель или гиря», «штанга или гантели». Валидатор проверяет оба варианта.

## Инвентарь

Детали строятся в локальных координатах снаряда (`at`, `yaw` в элементе списка) через сборщик `b`:
`b.tube(k, a, b, [w,h] | r, opts)`, `b.box(k, c, size, {axes})`, `b.cyl(k, c, axis, r, len)`,
`b.ball(k, c, r)`, `b.anchor(k, p)`, `b.frameAnchor(k, c, axes)`.
`opts`: `mount` — к какой детали этого же снаряда крепится (`'floor'` — стоит на полу),
`role` (`support` — опора тела, `grip` — ручка, `frame`, `guide`), `tone` (`frame`, `pad`, `chrome`,
`rubber`, `plate`, `stack`, `wood`, `wall`, `mat`, `cable`, `band`, `rope`, `towel`).

**Правила, которые проверяет валидатор и которые важны пользователю:**

1. Реальные размеры (см): скамья 44 до верха подушки, ширина 29; сиденья тренажёров 45–50;
   гриф 220 / шейка 131 / Ø2,8, диск 20 кг Ø45; гантель — рукоять 13,5, головы Ø15; гиря 16 кг — шар Ø21,
   рукоять на 15 см выше центра шара; турник Ø3,2 на высоте 225–235; брусья 115–125, расстояние
   между ними 50–55; блоки Ø9–10; стойки 7,5×7,5; профиль рамы 5–10. Если не уверены — берите
   типовые размеры коммерческих тренажёров.
2. Каждая деталь крепится к реальной детали (`mount`), цепочка доходит до пола. Ничего не висит.
   Опоры стоят на полу (нижняя точка — на Y = 0).
3. Подвижные части тренажёра следуют за телом через `BIND`: рычаги (`lever` — ось неподвижна,
   конец идёт за точкой тела: валик к голени, рукоять к хвату), каретки (`sled` — по направляющей),
   тросы (`cable` с рукоятями `D`, `rope`, `bar`, `V`, `ankle`), педали (`crank`, `footPedals`),
   сиденье гребного (`slideSeat`). **Ось рычага тренажёра совпадает с осью сустава**, который он
   нагружает (колено — разгибание и сгибание ног; плечевой сустав — «бабочка»; тазобедренный —
   отведение ног), — так это устроено в настоящих тренажёрах.
4. Трос идёт от блока к рукояти и не проходит сквозь тело. Блок закреплён на колонне.
5. Свободный снаряд всегда в руке или на опоре.

Новые типы тренажёров добавляйте в свой файл `src/js/09bo-<группа>.js`:

```js
/* Тренажёры группы … */
((E) => {
  const M = typeof Mannequin !== 'undefined' ? Mannequin : require('./09bm-mannequin.js');
  const { V, M3, D2R, toCat, dirCat } = M, { TYPES, BIND } = E;
  TYPES.legExtension = (s, b) => { /* … */ };
})(typeof GymEquipment !== 'undefined' ? GymEquipment : require('./09bn-equipment.js'));
```

Код в этих файлах выполняется в браузере пользователя: только чистый JS без зависимостей,
без строк на кириллице в литералах (кроме комментариев).

## Проверка и ревью — обязательно для каждого упражнения

1. `node tools/mannequin/check.js --only <id>` — **0 ошибок**. Предупреждения допустимы, только
   если это действительно норма техники (пограничный угол 1–5°), и их нужно перечислить в отчёте.
2. Контактный лист: `node tools/mannequin/sheet.mjs --ids <id> --t 0,0.5,1 --cams angle,side,front --out qa/<id>.png`,
   затем **открыть PNG и посмотреть глазами** (Read). Проверяйте: техника соответствует подсказкам
   упражнения; осанка естественная (спина, шея, положение стоп); тело в равновесии; хват правильный
   (прямой/обратный/нейтральный); снаряд и тренажёр выглядят как настоящие; ничего не проходит сквозь
   ничего ни в одной фазе. Если сомневаетесь — смотрите ещё ракурсы (`back`, `above`).
3. Валидатор не видит «неестественность»: колени внутрь, «лебединую» шею, сваленный вбок корпус,
   стопы, вывернутые назад. Это ловит только взгляд. Сравнивайте с тем, как упражнение выполняют
   в хорошем зале.

## Чему научил пилот (`tools/mannequin/exercises/pilot.js`)

* Лёжа на скамье с прогибом используйте `restOn2('upperBack', 'buttocks', …)` — иначе таз висит над скамьёй.
* Для гантелей и гирь — `hold` с подобранной пронацией, а не `grip` с жёсткой осью: иначе запястье
  выворачивается и гантель упирается в корпус. В конце тяги гантели чуть супинируйте (`pron` −15…−20).
* Прямой хват на горизонтальном грифе — большой палец к другой руке (`thumb = −lat`), обратный — наружу.
* Опорная рука на скамье: пальцы чуть внутрь (`fingers` с наклоном к центру), иначе пронация за пределом.
* Сидя спиной к спинке: сначала `restOn(…'buttocks'…)` на сиденье, потом `restOn(…'back'…)` к спинке.
* Колени смотрят туда же, куда носки: полюс колена ≈ направление стопы (плюс немного наружу).
* Если рука или нога «не дотягивается», не растягивайте сегменты — меняйте позу или размещение снаряда.
* Ось и положение тренажёра считайте из позы (например, оси «бабочки» — над плечевыми суставами):
  раскладку можно вычислить один раз при загрузке модуля (`once(...)`) и использовать в `equipment`.
* Уровень детализации инвентаря — как в пилоте: рама из профиля, подушки, ручки, блоки, стек грузов.
