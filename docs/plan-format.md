# Файл плана Lazy Gym Planner (версия 1)

Свои планы выгружаются в JSON: «Свой план» → «Выгрузить». Файл открывается в приложении на любом
устройстве: «Свой план» → «Загрузить план» (файл или вставленный текст). Код — `src/js/11e-plan-files.js`,
тесты — `tools/plan-files.test.js`.

Файл — не резервная копия: в нём нет журнала, замеров и настроек мест. Резервная копия
восстанавливается в «Журнале»; если её загрузить как план, приложение так и скажет.

## Пример

```json
{
 "format": "lazy-gym-planner/plans",
 "version": 1,
 "app": "4.10.0",
 "exported": "2026-10-09",
 "from": "Тренер Иван",
 "plans": [
  {
   "name": "Пн · Верх",
   "group": "Сила · неделя 1",
   "for": "Сергей",
   "note": "Без отказа, последний повтор с запасом",
   "goal": "strength",
   "format": "classic",
   "level": "mid",
   "items": [
    {"id": "bbbench", "name": "Жим штанги лёжа", "sets": 4, "rest": 180, "reps": "3–5",
     "tempo": "3-1-1-0", "kg": [60, 62.5, 65], "note": "Пауза 1 с на груди"},
    {"id": "latpull", "name": "Тяга верхнего блока", "sets": 3, "rest": 90, "reps": "8–10", "kg": 50}
   ]
  }
 ]
}
```

## Поля

Файл:

| Поле | Обязательно | Значение |
|---|---|---|
| `format` | да | всегда `lazy-gym-planner/plans` |
| `version` | да | версия формата, сейчас `1` |
| `app` | нет | версия приложения, выгрузившего файл |
| `exported` | нет | дата выгрузки, `ГГГГ-ММ-ДД` |
| `from` | нет | от кого (до 40 знаков) |
| `note` | нет | общая заметка к файлу (до 400 знаков) |
| `plans` | да | список планов, до 50 |

План:

| Поле | Значение |
|---|---|
| `name` | название (до 40 знаков) |
| `auto` | ключ имени по умолчанию, если план назвало приложение (с версии 4.100.0): `my` — «Мой план», `plan:2` — «План 2», `day:0:up` — «Пн · Верх», `groups:chest,back` — «Грудь и спина», поправки `+copy` — «… — копия» и `#2` — «… (2)». Получатель видит имя на языке своей версии; если ключа нет или он незнакомый — имя из `name`. Прежние версии ключ пропускают |
| `group` | программа: планы с одинаковой программой показываются вместе (например, дни одной недели) |
| `gauto` | ключ имени программы по умолчанию (с версии 4.100.0): `split:ul:1` — «Верх / низ · неделя 1» |
| `for` | для кого |
| `note` | заметка к плану (до 400 знаков) |
| `goal` | `strength`, `mass`, `cut` или `gentle` (бережно, с версии 4.11.0; более ранние версии пропустят цель и возьмут свою) |
| `format` | `classic`, `superset`, `circuit` или `static` |
| `level` | `beg`, `mid` или `adv` |
| `items` | упражнения по порядку, до 12 |

Упражнение:

| Поле | Значение |
|---|---|
| `id` | код упражнения из каталога; общий для русской и английской версий |
| `name` | название для человека; приложение его не читает |
| `sets` | подходы, 1–10 |
| `rest` | отдых, секунды, 0–600 |
| `reps` | повторы: `8`, `8–10` или по подходам через `/` — `10/8/6/5` (2–10 значений; если подходов больше, повторяется последнее число; прежние версии такую строку пропускают и берут повторы по цели); у удержаний и кардио повторов нет — время задаёт цель |
| `tempo` | темп: четыре числа или `X` через дефис, например `3-1-1-0` |
| `kg` | рабочий вес в килограммах: число или список по подходам (до 10 значений, до тысячных килограмма — вес, вписанный в фунтах, у получателя в фунтах тем же числом; версии до 4.100.0 округляют до 0,25 кг); если подходов больше, повторяется последний вес. Единицы, в которых вес показывается (кг или фунты), — настройка получателя, в файл не пишутся |
| `note` | заметка к упражнению (до 200 знаков) |

Подходы, отдых и повторы приложение пишет явно — так, как их видно в плане у отправителя, поэтому у
получателя план выглядит так же, даже если у него выбраны другие цель и формат. В круговом формате
подходы и отдых задаёт круг, поэтому у упражнений их нет. В статодинамике повторы и отдых задаёт метод,
`sets` — число подходов (по три на серию), если его меняли.

## Как читается файл

* Добавляется всегда новыми планами; ничего не перезаписывается. Занятое имя получает номер: «Верх (2)».
* Имя по умолчанию (`auto`, `gauto`) пишется на языке версии получателя: план «Мой план» из русской версии в
  английской — «My plan». В файле без ключа (прежние версии) имя по умолчанию на русском или английском узнаётся
  по самому имени; имя, которое дал человек, остаётся как есть.
* Неизвестные упражнения пропускаются и перечисляются в предупреждении (по `name`).
* Значение вне допустимого пропускается, остальное в плане сохраняется; повторы одного упражнения убираются.
* Файл новее версии 1 загружается с предупреждением: незнакомые поля пропускаются.
* Один план без обёртки (`{"name": …, "items": […]}`) тоже читается.
* Файл больше 256 КБ не читается.
