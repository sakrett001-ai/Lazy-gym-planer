# Кожа Anny: проба (шаг 0) и подгонка с осанкой скелета (шаг 1)

План «анатомия до идеала»: кожу манекена (процедурные сечения `TORSO`/`FOLDS` в `src/js/09bm-mannequin.js`) заменить
формой параметрической модели **Anny**. Наш скелет MyoSim, мышцы, кинематика пояса, шея и гортань остаются. Код
приложения инструменты не меняют; сам Anny в репозиторий не кладётся.

## Что нужно

- Python 3.10+, `torch` (CPU), `anny` 0.6.1, `trimesh`, `rtree`, `scipy`, `roma`, `safetensors`, `pyyaml`, `pillow`, `embreex` (лучи trimesh в 5–10 раз быстрее; без него подгонка — часы);
- Node и зависимости репозитория (`npm ci`), Chromium для Playwright;
- для шага 1 — клон MyoSim (как у `tools/skeleton/build_bones.py`, переменная `MYOSIM`): полные сетки позвонков.

```
pip install --break-system-packages torch roma safetensors trimesh pyyaml pillow requests rtree scipy fast-simplification embreex
pip download --no-deps anny==0.6.1 && pip install --break-system-packages --no-deps anny-0.6.1-py3-none-any.whl
```

Колесо `anny` (47 МБ, PyPI) уже содержит все нужные ассеты: базовую сетку и формы MakeHuman (`anny/data/mpfb2`),
риг (`mpfb2/rigs/standard`), кэш форм (`data/cached/anny.pth`). Топологию SMPL-X (некоммерческая лицензия) инструменты
не используют и не скачивают.

## Шаг 1: как запускать

`W` — папка для промежуточных файлов (вне git).

```
node tools/skin-anny/mannequin.js export --root . --out $W/m461.json          # скелет 4.61.0, суставы, anthro.js
python3 tools/skin-anny/endplates.py --out $W/endplates.json                  # пластинки позвонков по полным сеткам MyoSim
python3 tools/skin-anny/anny_fit.py --mannequin $W/m461.json --out $W/fit0.json --iters 15    # старт: Anny под медианы (шаг 0)
python3 tools/skin-anny/posture_start.py --work $W                            # старт осанки: только нормы, череп −12° (HAT)
python3 tools/skin-anny/fit_joint.py --work $W --out $W/j1.json --pose-iters 6 --iters 6 --sweeps 12     # совместная подгонка
python3 tools/skin-anny/fit_joint.py --work $W --out $W/joint.json --resume $W/j1.json --iters 0 --pose-iters 0 \
        --head-start --head-sweeps 10 --sweeps 2                               # голова заново: без крайних масштабов
python3 tools/skin-anny/look_sheet.py --work $W --fit $W/joint.json --out $W/look-sheet.png --result tools/skin-anny/result
```

`preview.py` — быстрый просмотр промежуточного `joint.json` (кадры и сводка невязок). Подгонка идёт этапами: только поза
Anny и посадка скелета (Гаусс — Ньютон), всё вместе (Гаусс — Ньютон с областью доверия), затем поиск по координатам —
невязки негладкие (оболочки сечений, «наибольшее из колец», лучи), и у минимума якобиан конечными разностями перестаёт вести
вниз, а перебор ещё находит спуск. `--resume` продолжает по именам параметров (набор форм можно менять). Результат листа
получен цепочкой таких запусков при отладке (≈ 3 ч счёта на 2 ядрах); повтор по рецепту выше даст близкий, но не тот же до
бита.

## Шаг 1: что сделано

**Осанка скелета** (`spine.py`). Кости не меняются — меняется их посадка: цепочка «таз — L5 … L1 — грудной блок — C7 … C3 —
блок C2 + атлас — череп», повороты вокруг центров дисков (центр между замыкательными пластинками соседей), поворот рёбер
в рёберно-позвоночных суставах (ось шейки ребра: головка — бугорок; рёбра 1–10 — доля 0,4…1, грудина с хрящами — за
концами рёбер 1–7), наклон черепа и нижней челюсти вокруг ямок атласа. Голова (рамка головы) и тазобедренные суставы —
на месте: сумма всех поворотов цепочки и положение ямок атласа — замыкание (блок C2 + атлас конгруэнтен черепу, как в
HAT). Углы — по пластинкам полных сеток MyoSim (`endplates.py`), как на боковом снимке. Нормы — `norms.POSTURE`: PT, SS и
LL — по PI таза MyoSim (Le Huec, Hasegawa 2016; разброс — Vialle 2005), T1 slope — Knott 2010, шея — Columna 2018 и
Hardacker 1997, SVA < 5 см, высоты C7, яремной вырезки и 10-го ребра — ANSUR II.

**Anny** (`anny_pose.py`). Суставы рига конечностей — наши: бедро поворачивается вокруг центра головки бедра, голень —
вокруг коленного, плечо — вокруг плечевого, предплечье — вокруг локтевого; сегмент ставит сустав рига Anny на своём конце
на наш сустав (колено Anny — на нашем колене). Корпус — позой её рига (поясница и грудной отдел spine05…01, шея, голова,
ключицы — подъём и отведение: плечевой пояс Anny — к нашему плечевому суставу), сдвиг — вверх-вниз и вперёд-назад. Пах —
форма «bulge» −1 и лапласово сглаживание паховой области (гладкая нейтральная форма).

**Совместная подгонка** (`fit_joint.py`): фенотип и 54 местные формы Anny, 11 параметров её позы и 15 параметров посадки
скелета. Невязки: ANSUR II «подтянутый» (`norms.ANSUR_TONED`: талия и ягодицы — к p25, грудь, плечи, обхваты рук — к p75,
остальное — медиана), длины сегментов рига, подошва на полу, ткани над 44 ориентирами (с черепом: темя, надпереносье,
переносица, подбородок, низ подбородка, угол челюсти, скуловая дуга, затылок, бок свода), кости снаружи кожи (с гортанью),
место для длиннейшей на T3–T10, ткани над лопаткой, осанка по нормам и замыкание шеи на череп, наклон черепа — к посадке
HAT (−12 ± 4°). Лицо на черепе — с весом 2; общий масштаб головы, её «жир», лоб и высота подбородка — дорогие правки
(ими подгонка сплющивала голову спереди назад и вытягивала вверх — та самая «сплющенная голова» Anny-Б).

**Anny подтянутая** (таблицы листа): рост 175,4; грудь 102,3 × 31,2 × 26,8 (обхват, ширина, глубина); талия 78,1 × 27,4 ×

манекена, ключица 0,7 вместо 3,5, гребень таза 4,0 вместо 7,1. Место для длиннейшей на T3–T10 — 1,9–2,9 см (4.61.0 —

надключичная ямка 0,9, яремной ямки нет.

**Что не сошлось:**
- *Грудь шире и глубже p75, талия уже p25*: грудная клетка MyoSim с нормой тканей над рёбрами не помещается в грудь ANSUR
  p75 (ширина 31,2 при p75 29,1; глубина 26,8 при 25,2), и подгонка «отдаёт» талию (78,1 при p25 84,6) — фигура с выраженным
  V; бёдра и голени — ниже p25 (57,1 и 36,5). В средней половине людей 15 замеров из 28 (манекен 4.61.0 — 23), у цели «подтянутого» (± четверть IQR) — 13 из 28.
- *Нижние рёбра выше нормы*: 10-е ребро 114,6 (p75 113,4), уровень L2–L3; выдох больше 4° подгонка не берёт — кожа Anny
  под нижними рёбрами узкая.
- *C7 низко относительно темени*: 149,0 при медиане 150,7 — с черепом MyoSim и шеей его длины до медианы не дотянуть (нужно
  укоротить шею на ≈ 2 см).
- *T1 slope 31°, шейный лордоз 7,6°* — в пределах 1 СКО, но у края; грудной кифоз — как у MyoSim (блок твёрдый).
- *Шея*: гортань и трахея выходят из кожи спереди на 1,1–1,5 см, остистые C2–C6 — сзади на ≈ 1 см: шея Anny тоньше
  спереди назад, чем шея скелета с гортанью 4.61.0 (`airway.js`).
- *Лицо*: надпереносье −0,2 (кость у самой кожи), низ подбородка 0,0, верхняя челюсть и нос черепа местами у кожи; длина
  головы 19,2 (p25 19,5).
- *Поясница*: остистые L4–L5 выходят на 1,1–1,3 см (было 1,8–3,8) — лордоз кожи Anny всё ещё глубже лордоза скелета.
- *Запястье*: шиловидный локтевой отросток снаружи на 1,4 см, лучевой — 1,9 см под кожей: предплечье Anny закручено
  иначе, чем наше в нейтральной пронации.
- *Пах*: гладкая форма сглаживанием — на кадрах светлее соседней кожи (другая кривизна).


**Из ветки осанки (`feat/anatomy-posture`, 9f13c1f)** перенесено как правило, а не как код: шея подвешена к черепу (блок C2 +
атлас конгруэнтен черепу, как в HAT; C2 впереди C7 — cSVA по Hardacker 1997 / Columna 2018), T1 slope — Knott 2010. Не
перенесено: вынос передней стенки грудной клетки (отменён владельцем), сжатие грудного блока до 28 см (масштаб костей без
нужды — цепочка замыкается и так), удлинение C2 в 1,6 раза (не понадобилось), отведение ключицы на 19° по Ludewig 2009
(плечевой сустав уходит назад на 2,7 см, а пояс Anny и так ставится к нашему суставу: подъём 5,8°, отведение 14,5° позой её
рига) — решать при встраивании мышц вместе с DAS3. Верхние зубцы передней зубчатой (Smith 2003) и исключение цвета нижней
трапециевидной в Y-T-W (Ekstrom 2003) — данные мышц: брать при пересборке мышц на новой посадке (коммиты 0c0a770, f5a39ff).

## План встраивания (следующий заход, после одобрения листа)

1. **Посадка скелета** — `tools/skeleton/build_bones.py` по `result/posture-patch.json` (SKEL_CFG): наклон таза — поворот
   `pelvisMap` вокруг оси тазобедренных; поясница — цепочкой от S1 (вместо доли w), грудной блок — по ней; рёбра — поворот
   вокруг оси шейки (рёбра — отдельные компоненты сетки `ribcage`), грудина — за концами рёбер 1–7; шея — цепочкой от T1 к
   конгруэнтному блоку C2 + атлас; череп и челюсть — поворот вокруг ямок атласа в `skullP`/`jawP`. Мышцы — теми же `XF`
   (`build_muscles.py` → `das3_import.py` → `gait2392_import.py` → `anatomy.js` → `pack.js`), `airway.js` — к новым уровням
   позвонков. Проверки: `tools/skeleton.test.js`, `tools/muscles.test.js`, `npm run muscles:check`, `node tools/muscles/attach.js --audit`.
2. **Рамки манекена** (`09bm-mannequin.js`): `B.neckPivot`, `B.lumbarPivot`, `B.thoracicPivot`, `VERT_LEVELS` — по новым
   центрам дисков; `B.sc` — сдвиг пояса за рукояткой грудины (`girdle_shift_cm`). Это меняет кинематику всех поз —
   `npm run mannequin:bake`, валидатор 0 ошибок (`npm run mannequin:check`), `tools/joint-stress.test.js`, `girdle-audit.js`.
3. **Кожа из Anny** (шаг 2 плана шага 0): плотные таблицы сечений корпуса, шеи и конечностей по сетке Anny в нейтральной
   стойке вместо `TORSO`/`LIMBS`/`NECK`/`HEAD_*`; `torsoSDF`, `limbSDF`, `headSDF`, `neckSDF`, `torsoPointIn` и их потребители
   остаются. Складки подмышки — `folds-fit.js` заново или замена корректирующими формами. Проверки: `anthro.js` (ANSUR II),
   `npm run skeleton:fit` (≤ 1,5 см во всех упражнениях), `npm run muscles:check`, контакт с опорами в `compose.js`,
   `holds-audit.js`, `catalog-render-audit.mjs`, `tools/muscle-phase.test.js`.
4. **Сетка Anny как видимая кожа** (шаги 3–4 плана шага 0): скиннинг по нашим сегментам, суставы рига — `rig_joints_rest_m`
   из `result/anny-toned.json`, веса — перенос с рига Anny; корректирующие формы плеча, подмышки, бедра, колена. Тест
   «сетка — таблицы» (≤ 2 мм в покое), `third_party/anny` (Apache 2.0), `npm run check`, `npm run mannequin:review` —
   ревью владельцем по группам упражнений.

## Итоги пробы (шаг 0, 22.10.2026)

- **ANSUR II.** Anny после подгонки — 29 из 35 замеров в средней половине людей (манекен 4.61.0 — 27).
- **Глубина груди по средней линии.** Кожа Anny на высоте h 45–51 см над тазобедренными на 4,6–6,1 см мельче кожи
  манекена. Скелет 4.61.0 в Anny влезает без тканей (сумма над грудиной и остистым 0,8 / 0,0 / −0,4 см при норме 1,3–4,2),
  скелет ветки осанки (`feat/anatomy-posture`, 9f13c1f) — не влезает.
- **Опыт «Anny под скелет с осанкой»**: ткани над остистыми в норме, но глубина груди 27,8 см (p75 — 25,2): грудная клетка
  ветки осанки глубже, чем позволяет ANSUR II.
- **Рельеф Anny:** борозда позвоночника 0,7–1,1 см, лопатки выступают на 1,7–1,9 см; яремной и надключичной ямок нет.
- **Расхождения осанки:** поясничный лордоз Anny глубже (L1–L5 выходят из кожи на 1,8–3,8 см), лицо и челюсть MyoSim не
  совпадают с лицом Anny (до 3,5 см), пояс Anny на 2,9 см впереди, сустав рига Anny — на ≈ 2,5 см латеральнее головки бедра.
