# Проба кожи (шаг 0): Anny против манекена

Разовая проба для плана «анатомия до идеала»: подходит ли параметрическая модель тела **Anny** как форма кожи
в покое и что получится, если вписать в неё наш скелет — нынешний (4.61.0) и с осанкой из ветки
`feat/anatomy-posture` (9f13c1f). Код приложения проба не меняет; сам Anny в репозиторий не кладётся.

## Что нужно

- Python 3.10+, `torch` (CPU), `anny` 0.6.1, `trimesh`, `rtree`, `scipy`, `roma`, `safetensors`, `pyyaml`, `pillow`;
- Node и зависимости репозитория (`npm ci`), Chromium для Playwright.

```
pip install --break-system-packages torch roma safetensors trimesh pyyaml pillow requests rtree scipy
pip download --no-deps anny==0.6.1 && pip install --break-system-packages --no-deps anny-0.6.1-py3-none-any.whl
```

Колесо `anny` (47 МБ, PyPI) уже содержит все нужные ассеты: базовую сетку и формы MakeHuman (`anny/data/mpfb2`),
риг (`mpfb2/rigs/standard`), кэш форм (`data/cached/anny.pth`). Скачивать с хостов NAVER ничего не нужно: оттуда
грузится только топология SMPL-X (некоммерческая лицензия) — проба её не использует. Индекс `download.pytorch.org`
в этой среде закрыт, поэтому `torch` ставится с PyPI (сборка с CUDA, работает и на процессоре).

## Как запускать

`W` — папка для промежуточных файлов (вне git), `POST` — временная копия ветки осанки:

```
git worktree add --detach $POST 9f13c1f && ln -s $PWD/node_modules $POST/node_modules
node tools/skin-probe/mannequin.js export --root . --out $W/m461.json        # скелет 4.61.0, суставы, anthro.js
node tools/skin-probe/mannequin.js export --root $POST --out $W/mpost.json   # то же для ветки осанки
python3 tools/skin-probe/anny_fit.py --mannequin $W/m461.json --out $W/fit.json --iters 15
python3 tools/skin-probe/register.py --fit $W/fit.json --skeleton $W/m461.json --root . --label 4.61.0 --out $W/reg-461.json
python3 tools/skin-probe/register.py --fit $W/fit.json --skeleton $W/mpost.json --root $POST --label posture --out $W/reg-post.json
python3 tools/skin-probe/sheet.py --work $W --out $W/contact-sheet.png
```

Кэш Anny — `ANNY_CACHE_DIR` (первый запуск собирает формы ≈ 1 мин).

Опыт «Anny под скелет»: `anny_fit_bones.py --fit $W/fit.json --skeleton $W/mpost.json --out $W/fitb-post.json`,
затем `register.py --fit $W/fitb-post.json --skeleton $W/mpost.json --root $POST --label postureB --out $W/reg-postb.json`
(лист добавит его ряд и столбцы сам).

## Итоги пробы (22.10.2026)

- **ANSUR II.** Anny после подгонки — 29 из 35 замеров в средней половине людей (манекен 4.61.0 — 27). Вне её: ширина
  груди 30,1 (p75 29,1), глубина ягодиц 24,9 (24,4), обхват плеч 117,8 (117,4) и точки скелета (C7, лодыжка).
- **Глубина груди по средней линии.** Кожа Anny на высоте h 45–51 см над тазобедренными (грудинный угол — вырезка) на
  4,6–6,1 см мельче кожи манекена (18,4 / 16,2 / 13,9 против 23,0 / 21,9 / 20,0 см). Сумма тканей над грудиной и над
  остистым (не зависит от сдвига вперёд-назад): скелет 4.61.0 в Anny — 0,8 / 0,0 / −0,4 см, скелет с осанкой — −1,9 /
  −1,7 / −1,5 см; норма 1,3–4,2. Скелет с осанкой в Anny не помещается совсем, 4.61.0 — без тканей.
- **Место для длиннейшей** (минус слой над столбом, как в walls.js ветки осанки) на h 39 / 45 / 51: манекен 4.61.0 — 2,3 /
  2,1 / 3,4; Anny + 4.61.0 — 1,4 / 0,5 / 0,5; манекен осанки — 1,4 / 1,2 / 1,4; Anny + осанка — 1,3 / 1,4 / 0,3 (нужно 2,2–3,7).
- **Опыт «Anny под скелет с осанкой»** (ANSUR II + нормы тканей над ориентирами корпуса): ткани над остистыми T1–T11 в норме
  (0,8–1,3 см), но глубина груди 27,8 см (p75 людей — 25,2), талия искажена, ANSUR в середине людей — 18 из 28 вместо 25.
  Грудная клетка ветки осанки глубже, чем позволяет средний мужчина ANSUR II.
- **Рельеф Anny:** борозда позвоночника 0,7–1,1 см, лопатки выступают на 1,7–1,9 см; яремной и надключичной ямок нет
  (у манекена — ни борозды, ни выступа лопаток, надключичная ямка 0,3).
- **Расхождения осанки:** поясничный лордоз Anny глубже (L1–L5 выходят из кожи на 1,8–3,8 см), лицо и челюсть MyoSim не
  совпадают с лицом Anny (до 3,5 см), руки и пояс Anny на 2,9 см впереди, ноги в стойке на 3 см шире (сустав рига Anny —
  на ≈ 2,5 см латеральнее центра головки бедра).

## Переход (оценка, без реализации)

1. **Грудная клетка и осанка скелета** — до смены кожи: глубина грудной клетки MyoSim (на ветке осанки — с вынесенной
   передней стенкой) против КТ-норм и ANSUR II; лордоз и кифоз — по рентгенометрии. Инструмент — `anny_fit_bones.py`
   (форма тела и скелет вместе). Проверки: таблица тканей, сумма тканей спереди и сзади, место для столбов спины.
2. **Форма покоя из Anny** в нынешней архитектуре: плотные таблицы сечений (корпус, шея, конечности) по сетке Anny вместо
   суперэллипсов `TORSO` и профилей конечностей — `torsoSDF`, `limbSDF`, `torsoPointIn` и все потребители (валидатор,
   `compose.js`, `Muscles.skinPart`, `anthro.js`, `skeleton/fit.js`, `muscles/check.js`, `walls.js`) остаются. Рельеф
   лопаток — по-прежнему подушкой над лопаткой (`cushLift`), он едет за поясом.
3. **Сетка Anny как видимая кожа** (вид «Манекен» и силуэт в «Анатомии»): скиннинг на видеокарте по нашим сегментам
   (веса — перенос с рига Anny, его тазобедренный сустав на 2,5 см латеральнее), проверки — по таблицам шага 2, сверка
   «сетка — таблицы» тестом (≤ 2 мм в покое).
4. **Корректирующие формы**: плечо (подъём руки 0–180°), подмышка (вместо `FOLDS`), тазобедренный и коленный при
   приседе, скручивание корпуса; веса форм — от углов суставов манекена.
5. **Весь каталог**: запекание, валидатор 0 ошибок, опоры и скамьи, ревью владельцем по группам.

Цена кадра на телефоне: сетка ≈ 13,3 тыс. вершин / 26,5 тыс. треугольников (есть упрощённые топологии Anny — 1,2 тыс.
вершин для карточек); скиннинг на видеокарте — процессору ≈ 0,1–0,3 мс (матрицы ≈ 20 сегментов и веса форм); `surface()`
нынешних колец (0,85 мс) уходит. Силуэт кожи в «Анатомии» — два прохода по 26,5 тыс. треугольников, на видеокарте
≈ 0,3–0,8 мс. Кожа кадра для мышц — таблицы, как сейчас. Загрузка: сетка, веса и формы ≈ 350 КБ (≈ 150 КБ gzip).

## Файлы

| Файл | Что делает |
|---|---|
| `mannequin.js` | Выгрузка манекена копии репозитория (нейтральная стойка, кости в мировых см, замеры `anthro.js`) и запросы к его коже (знаковое расстояние, лучи) — те же формы, что у валидатора и `tools/skeleton/fit.js`. |
| `anny_body.py` | Anny в координатах манекена (см, Y вверх, +Z вперёд, +X влево); перевод в нейтральную стойку манекена её же ригом. |
| `anny_measure.py` | Замеры ANSUR II на сетке Anny по уровням и правилам `anthro.js`. |
| `anny_fit.py` | Подгонка фенотипа и местных форм Anny под медианы `anthro-ansur2.json` (Гаусс — Ньютон, конечные разности). |
| `anny_fit_bones.py` | Опыт: та же подгонка вместе со скелетом — нормы тканей над ориентирами корпуса как дополнительные цели. |
| `landmarks.py` | Костные ориентиры на сетках MyoSim и нормы толщины мягких тканей с источниками. |
| `register.py` | Вписывание скелета в Anny по ориентирам (целиком и по сегментам), толщина тканей, выход костей, место для мышц спины, лопатка, рёбра, грудина, рельеф — для Anny и для кожи манекена той же копии. |
| `render-entry.mjs`, `render.mjs` | Кадры в студии объёмной сцены приложения (`src/volume/scene.mjs`: свет, тон, материал кожи) и сборка листа с таблицами. |
| `sheet.py` | Лист: ряды «манекен», «Anny», «скелет 4.61.0 в Anny», «скелет с осанкой в Anny» и таблицы. |
