# Правила для агентов и людей

Lazy Gym Planner — PWA-планировщик тренировок с атласом упражнений. Атлас показывает каждое упражнение
на трёхмерном манекене с настоящим инвентарём. Ошибка в позе (локоть выгнут назад, тело внутри
скамьи, гриф сквозь шею) делает продукт непригодным, поэтому для атласа действует обязательный процесс ниже.

## Публикация

* **Владелец разрешил автоматическую публикацию проверенных изменений `main`.**
  GitHub Actions выполняет `npm run check:all`, собирает неизменяемый релиз для Floot
  и обновляет `gh-pages` обычным fast-forward push. При ошибке проверок прежний сайт остаётся доступным.
  Сайт во Floot загружает эту сборку и проверяет её SHA-256; отдельная ручная публикация каждой версии не нужна.
* Работа идёт в отдельной ветке (`feat/...`); её можно пушить. Для ревью владелец получает просмотрщик
  (см. «Ревью») и контактные листы. Правки поз и тренажёров требуют ревью владельца до слияния в `main`.
* `deploy.sh` сам прогоняет проверку манекена и не публикует сборку, если в ней есть ошибки.

## Атлас: как устроены анимации

| Файл | Назначение |
|---|---|
| `src/js/09bm-mannequin.js` | Манекен: антропометрия de Leva/Winter, 47 степеней свободы, кинематика, поверхность тела. |
| `src/js/09bn-equipment.js`, `src/js/09bo-*.js` | Инвентарь и тренажёры в реальных размерах; подвижные части следуют за позой (`BIND`). |
| `tools/mannequin/exercises/*.js` | Спецификации упражнений: инвентарь, контакты, поза `pose(t, C)`. |
| `src/js/09bp-poses.js` | **Генерируется** `npm run mannequin:bake`. Руками не править. |
| `tools/biomech/validator2.js` | Валидатор биомеханики и столкновений. |
| `src/js/09f-joint-stress.js` | Красные метки пиковой нагрузки на суставы: правила по углам манекена (`Mannequin.jointAngles`, общий расчёт с валидатором), пороги и источники. |
| `docs/mannequin-authoring.md` | Подробное руководство по авторингу: координаты, помощники, приёмы. |

Запрещено:

* рисовать позы в 2D и «выдавливать» их в объём, двигать отдельные точки скелета в обход кинематики манекена;
* править `09bp-poses.js` вручную;
* ослаблять правила валидатора, чтобы упражнение «прошло». Порог меняется только с биомеханическим
  обоснованием и источником, отдельным коммитом, с повторной проверкой всех упражнений;
* менять пороги меток нагрузки на суставы без источника и без обновления `tools/joint-stress.test.js` (там для каждого правила перечислено, где метка обязана гореть и где — молчать);
* использовать для тренажёра «что-то похожее»: размеры берутся с реальных моделей, все детали соединены
  (правило креплений), подвижные части вращаются вокруг настоящих осей.

## Обязательный цикл для любой правки позы или тренажёра

1. **Спецификация.** Правка в `tools/mannequin/exercises/<группа>.js` (тренажёр — в `src/js/09bo-*.js`).
   Техника должна совпадать с подсказками упражнения в каталоге.
2. **Валидатор — 0 ошибок.**
   `npm run mannequin:check -- --only <id>` проверяет 41 кадр повторения: пределы суставов (с учётом
   двусуставных мышц), проникновение в опоры, пол, самопересечения, контакты стоп и кистей, крепления
   деталей, столкновения инвентаря, тросы, равновесие (с весом снаряда), скачки между кадрами, замкнутость цикла.
   Предупреждения разбираются: либо исправить, либо объяснить в описании коммита.
3. **Глазами — каждую фазу.**
   `npm run mannequin:sheet -- --ids <id> --t 0,0.25,0.5,0.75,1 --cams angle,side,front --out qa/<id>.png`
   и открыть картинку. Для циклических упражнений (`loop`) обязательно смотреть середину цикла.
   Чек-лист ниже.
4. **Запечь.** `npm run mannequin:bake` → `src/js/09bp-poses.js`.
5. **Полная проверка.** `npm run check` (тесты, полный прогон манекена, сборка).
6. **Ревью владельцем** до публикации (см. ниже).

### Чек-лист визуальной проверки

* Суставы гнутся в свою сторону: локти и колени не переразогнуты, кисть продолжает предплечье, стопа не вывернута.
* Тело лежит **на** опоре, а не в ней и не над ней: спина на скамье, таз на сиденье, стопы на полу или платформе.
* Снаряд в руке, а не рядом: гриф в ладонях, гантель в кулаке, рукоять обхвачена; трос не проходит сквозь тело.
* Тренажёр собран и стоит на полу; подвижные части движутся вместе с телом и не проходят сквозь раму.
* Равновесие правдоподобно: центр масс над опорой (или тело держится руками).
* Траектория как у живого человека: без рывков, амплитуда как в подсказках, темп разумный.
* Нет «тела в стене», «ног сквозь скамью», «головы в стойке» в **любой** фазе, а не только на краях.

## Ревью

```
npm run mannequin:review        # полный прогон + qa/mannequin-review.html
```

То же по шагам: `node tools/mannequin/check.js --samples 41 --json qa/check-all.json`, затем
`node tools/mannequin/viewer/build.mjs qa/mannequin-review.html --report qa/check-all.json`.

Просмотрщик — одна HTML-страница: все упражнения по группам, поиск, фильтр «с замечаниями», свободная
камера, ползунок фазы, переключатели вариантов инвентаря, список нарушений и углы суставов в кадре.

## Сборка и тесты

* `npm run build` — сборка в `dist/`; `npm test` — юнит-тесты (`tools/*.test.js`); `npm run check` — всё вместе.
* Контактные листы и отчёты складываются в `qa/` (не коммитится).
* Сообщения коммитов и тексты интерфейса — на русском; английский интерфейс — `i18n/en.json`.
